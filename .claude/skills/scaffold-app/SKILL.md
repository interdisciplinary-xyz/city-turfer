# Scaffold the CityTurfer app (historical)

**The app exists.** This skill records how milestone M1 was bootstrapped; don't re-run it.

- To add a native library: `pnpm -C apps/mobile exec expo install <pkg>` (versions match the SDK),
  then rebuild the dev build; it changes the runtime fingerprint.
- To add a JS-only library: `pnpm --filter @cityturfer/mobile add <pkg>`. Check `CLAUDE.md` first:
  some choices are settled (no zustand, no Firebase).
- To build a feature: the `add-feature` skill.

## Where the setup lives now

- App config: `apps/mobile/app.json` (no `app.config.ts`); bundle id and Android package
  `com.turftrack.poc`; plugins (`expo-router`, `expo-sqlite`, MapLibre, `expo-location` with
  background location and foreground service, local plugins in `apps/mobile/plugins/`).
- Autolinking exclusions: `apps/mobile/react-native.config.js` (HealthKit stays out of Android).
- Scripts: `apps/mobile/package.json` (`start`, `ios`, `android`, `typecheck`, `arch`, `test`,
  `test:e2e`…); repo-wide ones in the root `package.json` and `turbo.json`.
- Jest: the `jest` block in `apps/mobile/package.json` — `babel-preset-expo` through `babel-jest`,
  node environment, `@/` alias; real SQL through `better-sqlite3`
  (`apps/mobile/src/test-support/node-database.ts`), not a mocked `expo-sqlite`.
- Dependency rules: `apps/mobile/.dependency-cruiser.cjs`, run by `pnpm -C apps/mobile run arch`.
- Layout: `CLAUDE.md` (shared domain in `packages/core`, app contexts in
  `apps/mobile/src/contexts/`) and the `ddd-architecture` skill.
- Sign-in: `MockAuthGateway` in `apps/mobile/src/contexts/identity/infrastructure/` serves the local
  profiles and is always wired (decision B6 in `docs/plans/backend-plan-2026-10-22.md`); real
  accounts sign in by e-mailed code through `ApiAuthGateway`. There is no mock-mode switch.
- Native folders `ios/` and `android/` are generated by prebuild (CNG) and never committed.

## If you really are starting from an empty directory

1. Create the app in `apps/mobile` (not the repo root):
   `pnpm dlx create-expo-app@latest apps/mobile --template default`.
2. Install the stack from `CLAUDE.md` with `pnpm -C apps/mobile exec expo install …` (only what
   `CLAUDE.md` lists as installed; GPX export libraries come later).
3. Configure `apps/mobile/app.json` as above, build the DDD skeleton per `ddd-architecture`, wire
   Jest and dependency-cruiser as in the current `apps/mobile/package.json`.
4. Verify: `pnpm run typecheck`, `pnpm test`, then `pnpm ios` or `pnpm android`. Report which
   platform you actually launched, and say so plainly if you could not run a native build.
