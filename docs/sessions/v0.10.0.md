### Account settings (#142)

- **API 0.5.0 (additive):**
  - `PATCH /v1/me` changes the name.
  - Step-up codes go to the current address and are limited per account, so a stranger can't block
    them.
  - Email change (one address rule shared with sign-in).
  - `PUT` / `DELETE /v1/me/password`.
  - `{ email, password }` on `POST /v1/auth/sign-in`.
  - Email and password changes, and removing the password, sign out every other session.
  - Breached passwords are refused through the HIBP range API, which fails open.
  - No migration.
- **Phone (JS only):** Me › Account rows and flows for name, email and account password; "Use a
  password instead" on sign-in. The name replaces the user id on Profile and Home.
- **E2E:** Maestro flow `15-account-settings` (tag `account`, needs the local API with
  `AUTH_FIXED_CODE`; `run.sh` skips it when the API is down).
- **Reviewed twice**, by mobile-reviewer and then a four-lane team review (19 threads, all fixed and
  resolved). At merge: API 154 tests, core 167, mobile 435.
- **Not run:** the screens and flow 15 on a simulator or device, real HIBP calls from Vercel, Brevo
  delivery of the six new mails.
