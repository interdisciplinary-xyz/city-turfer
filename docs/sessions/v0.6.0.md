## Built

The work started on `scope/v0.5.0` in worktree `~/Code/turf-track-sb`, kept apart from the v0.5.0

**#78 `[1/2] feat/storybook-local-route`:** the design system at https://cityturfer.local/storybook

- `apps/web/tools/storybook-route.mjs`: the website's dev server (`apps/web/server.mjs`, dev only)
  serves the static Storybook build (`pnpm -C apps/storybook run build`) under `/storybook`.
  - `/storybook` redirects to `/storybook/`.
  - Paths can't leave the build folder.
  - A missing build answers 404 with the build command.
- **Built copy, not a proxy:** Storybook's dev server loads from the site root (`/@vite/…`,
  `/sb-manager/…`), so it can't live under a sub-path. The static build uses relative URLs. Live
  editing stays on http://localhost:6006.
- **Tests:** 6 in `tools/__tests__/storybook-route.test.mjs` (mapping, traversal, redirect, content
  types, missing build, pass-through to Next).
- **Portless:** from a git worktree, portless prefixes the hostname with the branch
  (`storybook-local-route.cityturfer.local`). `npx portless alias cityturfer <port>` maps the plain
  name. Documented in `CLAUDE.md` and the `design-system` skill.

**#79 `[2/2] feat/storybook-brand`:** CityTurfer look and full coverage

- **Theme:** `.storybook/theme.ts` (`create()` from `storybook/theming`) puts `@cityturfer/brand`'s
  `DARK` palette, `ACCENT` and the website's font stack on the sidebar, toolbar, panels and docs
  pages (`manager.ts`, `parameters.docs.theme`).
- **Logo:** the sidebar shows the mark and the "City/Turfer" wordmark (HTML `brandTitle`); the tab
  icon is the mark (`manager-head.html`). Brand SVGs are served at `brand/` from
  `packages/brand/svg`, with relative URLs so they work under `/storybook`.
- **Docs pages** for every component: `@storybook/addon-docs` 10.6.2 and `tags: ['autodocs']`.
- **New stories:** `Website/HeroCopy`, `Website/HeroScreens`, and `Website/Page` (the whole landing
  page, `Launch` and `BeforeLaunch`). That makes 33 stories and 15 docs pages.
- **Coverage rule:** every `@cityturfer/ui` export and every website component has a story. The
  mobile screen cards that read live app data aren't covered (Apple Health, Turf gained,
  Achievements, Onboarding, live-session banner). Each joins when its display part moves to
  `@cityturfer/ui` (`design-system` skill).
- **Headless screenshots** of hero stories without reduced motion catch the entrance animation
  before it runs. Use `--force-prefers-reduced-motion`.
