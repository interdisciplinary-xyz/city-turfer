### Language switch reloads the page (#168)

- Found on 2026-10-25 on `release/v0.11.0`: switching EN ⇄ PL showed the Next.js dev error
  "Encountered a script tag while rendering React component".
- Cause: each language is its own root layout (`apps/web/src/app/[locale]/layout.tsx` owns
  `<html>`). next-intl's client-side `Link` made React rebuild `<html>` in the browser. That dropped
  the `loaded` class set by the boot script in `<head>`, so HeroMotion waited for an event that
  never came and the hero stayed `visibility: hidden`. Production had the same hidden hero, without
  the warning.
- Fix: `LanguageSwitcher` renders plain `<a>` links with the same hrefs (`getPathname`); a language
  switch is a full page load. The portal's link still keeps the page and query.
- `next/script` `beforeInteractive` was ruled out: in the App Router it runs only when Next's
  runtime boots, too late for a before-first-paint script.
- Checked: headless Chromium repro before and after; web `tsc`, `eslint`, `test:unit` (54 + 172);
  portal Playwright 21/21.
