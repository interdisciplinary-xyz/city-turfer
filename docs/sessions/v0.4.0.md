# Session log — v0.4.0 (2026-10-18 →)

v0.4.0 starts with v0.3.0 released: the repo is a pnpm + Turborepo monorepo with the Expo app in
`apps/mobile` and the landing page in `apps/web` (English + Polish). Details of that work:
`docs/sessions/v0.3.0.md`.

## Decisions

- **iOS distribution:** no paid Apple Developer Program for now ($99/year), so no TestFlight or
  ad-hoc builds. iOS testers are limited to the founder's iPhone (Xcode reinstall with a free Apple
  ID, then OTA). The 7-day test week runs on Android.
- **Android distribution:** sideloaded APK, no Play Store. Built in the cloud with **EAS Build**,
  hosted on **Vercel Blob**, linked from the landing page. Testers: friends' phones only.
- **Waitlist:** **Brevo** with double opt-in; the controller is the founder as an individual. The
  landing page stays static: the browser posts straight to Brevo, no server or cookies.
- **Motion:** GSAP + `@gsap/react` on the landing page, with a `web-motion` skill and a
  `web-engineer` agent.

## Built

**#58 `chore/release-app-json-format`** (merged 2026-10-18)

- The `app.json` version updater replaces only the `expo.version` string and checks the result, so
  release bumps keep the file's formatting. Tests: byte-for-byte bump, failure without
  `expo.version`, round trip of the real `app.json`.
- `apps/mobile/app.json` formatted again.
- The OTA guide (`docs/operations/ota-release.md`) now says any edit under `apps/mobile/plugins/`
  needs a reinstall, formatting included.

**#60 `feat/web-hero-center`** (merged 2026-10-18)

- The hero fills the screen and its content is centred vertically under the EN/PL switch.
- On phones the logo, wordmark and headline scale with the width; at 320 px "Own your streets."
  stays on two lines.
- Short landscape screens get a tighter layout.

**#61 `fix/status-bar-dark-screens`** (open)

- Sign-in and the Turf Map are always dark. With the phone in light mode, their status-bar icons
  were dark on dark (seen on the Android emulator).
- `apps/mobile/src/ui-kit/use-light-status-bar.ts` sets light icons while those screens are focused.
- JS only, so it ships as an OTA.

**[1/3] #62 `feat/android-apk`** (open)

- **EAS profile** `android-apk` (`apps/mobile/eas.json`):
  - APK for arm64-v8a only: 54 MB, down from 137 MB universal
  - OTA channel `production`
  - EAS manages the version code (remote, auto-increment) and the signing key
- **Crash found on the emulator:** recording crashed on the first location update.
  - Cause: `RECEIVE_BOOT_COMPLETED` was missing from the explicit permission list in `app.json`
    (expo-task-manager schedules a persisted job).
  - Fixed, and duplicate permissions removed.
  - New runtime fingerprints: Android `3ef29bb7…`, iOS `792e05e3…`.
- **EAS build 4** (versionCode 4, version 0.3.0): SHA-256
  `dfb9ec6e57398ccf214fa112a59218b054b25a104bae6ddb7c9e84d49c4eed76`.
- **Publish script:** `pnpm -C apps/mobile run android:publish` uploads `android/cityturfer.apk`
  (the stable link) plus a versioned copy to Vercel Blob.
- **Website:** the "Download for Android" button shows when `NEXT_PUBLIC_ANDROID_APK_URL` is set.
- `fingerprint.config.js` ignores `eas.json`.
- Guide: `docs/operations/android-release.md`.
- **Emulator:** Android SDK cmdline-tools installed into `~/Library/Android/sdk` (Homebrew's
  `avdmanager` could not find the system image); AVD `cityturfer-api35`.
- **Maestro on the release APK:**
  - 01–05 pass, including recording and background recording.
  - 07, 08 and 09 pass on their own.
  - 06 and 10 need the dev-only demo seeder, which is hidden in release builds.
  - No crashes in logcat.
  - New `e2e/subflows/back.yaml`: the iOS "Back" label doesn't exist on Android.
- Problems on the way:
  - An overloaded emulator made Maestro time out (`eraseText`); a cold boot fixed it.
  - A recording left over from the crashed build blocked sign-out until the app data was cleared.

**[2/3] #63 `feat/web-waitlist`** (open)

- Brevo sign-up form with double opt-in, posted from the browser (`no-cors`).
- Fields: email, an explicit opt-in checkbox, a honeypot and the language.
- The privacy note names the controller, Brevo (EU), the purpose and a deletion contact.
- Shown only when `NEXT_PUBLIC_WAITLIST_FORM_URL`, `NEXT_PUBLIC_WAITLIST_CONTROLLER` and
  `NEXT_PUBLIC_CONTACT_EMAIL` are set. Copy in EN and PL.

**[3/3] #64 `feat/web-motion`** (open)

- **GSAP entrance:** logo, wordmark, headline lines, copy, then the phones; the turf-ramp headline
  glows slowly.
- **Pointer tilt** on the phones (desktop pointers, ≥ 960 px).
- **Pre-paint boot script:** content hides only while motion is on and comes back after 2.5 s if the
  animation never starts. Reduced motion shows everything at once.
- **Waitlist** moved into its own centred section under the hero (`#waitlist`), from the local
  review.
- **Claude Code:** `web-motion` skill and `web-engineer` agent (listed in `CLAUDE.md`).
- `apps/web/tools/viewports.mjs` renders pages at exact sizes, including under Chrome's ~500 px
  window minimum, with `--reduced-motion`.
- **Problems found:**
  - The boot script's class on `<html>` caused a hydration warning (`suppressHydrationWarning`).
  - A synchronous Chrome call deadlocked the viewport tool (now async).
  - Headless Chrome is too slow to show GSAP end states, so layout checks use `--reduced-motion`.
