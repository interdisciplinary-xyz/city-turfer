# Session log — v0.1.0 (2026-10-15)

From an empty folder to **CityTurfer v0.1.0**: a working iOS proof of concept on a real iPhone, with over-the-air updates, a GitHub repository, quality gates and an end-to-end regression suite.

## Product

- **CityTurfer** — _Surf your city. Own your streets._ (formerly TurfTrack). Record walks, runs and rides; every street you cover becomes your **turf** on an H3 hexagon grid (~50 m cells), permanent, glowing brighter with repeat visits.
- Decisions: single user, data on device; mock sign-in `admin@turftrack.com` / `admin1234`; turf is permanent (no decay); Turf map always dark; corridor turf (no closed-loop areas); MapLibre + OpenFreeMap (no Google key); iOS first (Android SDK not installed on this Mac).

## Verified

- `npm run ci:quality`: Prettier, ESLint, tsc, DDD dependency rules, **24 Jest tests** (domain invariants, fixture accuracy vs oracle ±3 %, full context chain incl. crash between steps, idempotency, delete releases turf).
- **E2E (Maestro, iOS 27 simulator):** auth, record run with pause/resume, background recording, too-short discard, history/detail, turf map + filters, delete, sign-out — **8/8 flows passed in 6 min 29 s** from a clean slate (`npm run test:e2e`).
- Simulator: 90 s backgrounded recording, no gap (max 3 s between points).
- Real device: first rides recorded in Warsaw (6 activities, 249 cells / 0.49 km²).

## Problems found & fixed today

| Problem                                                             | Fix                                                                                              |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Expo SDK 57 needs Xcode 26.4+                                       | Updated to Xcode 27                                                                              |
| Xcode SPM hangs downloading MapLibre                                | `tools/fetch-maplibre-ios.sh` + `plugins/with-local-maplibre`                                    |
| iOS 27 crashes apps without scene lifecycle                         | `plugins/with-scene-lifecycle` (Expo's `ExpoAppSceneDelegate`)                                   |
| h3-js crashes on Hermes (`TextDecoder('utf-16le')`)                 | Hermes-safe loader `territory/infrastructure/h3.ts`                                              |
| Map stopped following the user                                      | Use MapLibre `onTrackUserLocationChange`                                                         |
| Long GPS gap counted as moving time                                 | Judge movement by distance covered for gaps > 5 s                                                |
| **Real ride: 1.5–4.5 min gaps drawn as straight lines (fake turf)** | Gaps > 45 s start a new segment; tracking diagnostics table to find the root cause (OTA shipped) |
| Updates disabled in first iPhone build / icons changed fingerprint  | Re-prebuild; brand icons staged until next reinstall                                             |
| Watchman broken (Homebrew)                                          | Disabled in Jest + Metro config                                                                  |
