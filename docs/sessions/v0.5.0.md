## Decisions (agreed with the founder, 2026-10-19)

- Tokens extend `@cityturfer/brand`; the web gets them as CSS variables from `cssVariables()`, not
  from a hand-copied map or a committed generated file.
- `packages/ui` (`@cityturfer/ui`): React Native components, peer dependencies only (no native code
  reaches the app's autolinking).
- `TurfLegend` is new UI: it lives in `@cityturfer/ui` and Storybook only. Placing it on the Turf
  Map is a later, visible change.
- The website is always dark; Storybook's light/dark toggle applies to the RN components.
- Storybook in `apps/storybook` (react-native-web + Vite); Vercel project created only after the
  founder says so.
