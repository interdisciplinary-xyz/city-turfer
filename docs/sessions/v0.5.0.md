# Session log — v0.5.0 (2026-10-19 →)

v0.5.0 starts from `scope/v0.4.0` at `a79ce6d` (Apple Health, #67). Goal: one design system for
`apps/mobile` and `apps/web`, shown in one Storybook, without any native change.

## Setup

- Worktree `~/Code/turf-track-v0.5.0` on `scope/v0.5.0`, cut from `scope/v0.4.0`. A parallel session
  tests v0.4.0 in the main checkout; this work stays out of it (and off its simulator, emulator,
  Metro on 8081 and the web dev server). Storybook runs on port 6006.
- Version pinned to 0.5.0 in the root and workspace `package.json` files. `apps/mobile/app.json`
  stays at 0.3.0: its `version` is part of the runtime fingerprint (checked: bumping it moves the
  iOS hash `2932ab55…` → `9e3ebf89…`), and v0.5.0 must ship over the air.

## Decisions (agreed with the founder, 2026-10-19)

- Tokens extend `@cityturfer/brand`; the web gets them as CSS variables from `cssVariables()`, not
  from a hand-copied map or a committed generated file.
- `packages/ui` (`@cityturfer/ui`): React Native components, peer dependencies only (no native code
  reaches the app's autolinking).
- `TurfLegend` is new UI: it lives in `@cityturfer/ui` and Storybook only. Placing it on the Turf
  Map is a later, visible change.
- The website is always dark; Storybook's light/dark toggle applies to the RN components.
- Storybook in `apps/storybook` (react-native-web + Vite); Vercel project created only after the
  founder says so.
