## Monorepo design

Full record: `docs/decisions/monorepo-turborepo-2026-10-18.md`. Decided:

- **Landing page goal:** static showcase only (what CityTurfer is, how turf works, screenshots,
  "coming soon"). No data collection, so no backend and no GDPR surface.
- **Web stack:** Next.js on Vercel. Static pages now; a waitlist or API routes can come later.
- **Package manager:** pnpm (replaces npm 10 + `legacy-peer-deps`).
- **Shared packages from day one:** `packages/brand` (colour tokens including the turf strength
  ramp, SVG mark and wordmark, tagline copy) and `packages/config` (tsconfig, ESLint, Prettier
  bases).

- **Layout:** `apps/mobile` takes the app with its Maestro flows and the mobile-only tools;
  repo-wide tools (docs audit, secret guard, log audit, release) and `docs/` stay at the root. One
  version, one tag, one CHANGELOG.
- **Migration:** three stacked PRs into `scope/v0.3.0`: `chore/pnpm-turborepo` (app still at the
  root) → `chore/apps-mobile` (move, reinstall on device) → `feat/web-landing` (shared packages,
  Next.js, Vercel).

Still open: the web domain.

## Monorepo migration

**[1/3] #48 `chore/pnpm-turborepo`** (merged 2026-10-18)

- pnpm 10.22.0 pinned in `packageManager`; `pnpm-lock.yaml` imported from `package-lock.json`, so
  versions are unchanged. `.npmrc`: `node-linker=hoisted`, `auto-install-peers=false`,
  `strict-peer-dependencies=false`. Install scripts allowed for `better-sqlite3` and
  `unrs-resolver`.
- Turborepo runs `typecheck`, `arch`, `test:unit` (cached); CI and Release workflows use pnpm.
- **Problem found:** with `auto-install-peers=true` pnpm installed peers npm never did (Reanimated,
  Worklets, Gesture Handler) and CocoaPods autolinked them. `auto-install-peers=false` (the real
  equivalent of `legacy-peer-deps`) restores the npm build's pods exactly.
- **Runtime fingerprint already changes here** (hoisted autolinking paths, `package.json` scripts),
  not only in [2/3]: no OTA until the reinstall after [2/3].
- Verified: 281 Jest tests, `pod install` matches npm, fresh dev build, Maestro 10/10, CI green.

**[2/3] #49 `chore/apps-mobile`** (merged 2026-10-18)

- The app moves to `apps/mobile` (`@cityturfer/mobile`) with its Maestro flows, native module,
  plugins and the mobile tools; repo-wide tools stay in `tools/`. Same 1,278 resolved packages,
  hoisted to the root.
- `apps/mobile/app.json` pinned to 0.3.0; `.versionrc.json` bumps root, app `package.json` and
  `app.json` together.
- `ios/` regenerated with `expo prebuild --clean` in `apps/mobile`: same pods as [1/3].
- Verified: 281 Jest tests, 26 tool tests, dependency rules, dev build from `apps/mobile`, Maestro
  10/10, OTA bundle export (1,339 modules). New runtime fingerprint `30e78edb…`.

**[3/3] `feat/web-landing`**

- `packages/config` (`@cityturfer/config`): Prettier config (was `.prettierrc.json`), tsconfig
  bases, ESLint flat presets `base`, `react-native`, `next`. Each workspace has its own
  `eslint.config.mjs`; Turborepo runs `lint` per package.
- `packages/brand` (`@cityturfer/brand`): colour tokens, name and copy, logo SVGs (moved from
  `apps/mobile/assets/brand`). `apps/mobile/src/constants/colors.ts` re-exports the tokens; a Jest
  test pins the ramp to `apps/mobile/tools/turf-preview.mjs`.
- `apps/web` (`@cityturfer/web`): Next.js 16 static export. Hero (mark, wordmark, tagline), how turf
  works, two app screenshots, privacy, "coming soon" footer. No cookies, forms or trackers.
- Screenshots: demo history seeded in the simulator around Warsaw Old Town (a public landmark, not
  the e2e fixture point), status bar fixed at 09:41.
- **Problem found:** with `react-dom` in the workspace, Expo added `web` to the app's platforms and
  the runtime fingerprint changed. `app.json` now lists `platforms: ios, android`, and
  `apps/mobile/fingerprint.config.js` skips `package.json` scripts (dev commands only), so the
  fingerprint is stable at `fb9fc2e8…`.
- **Vercel:** creating the project through the Vercel integration was refused (403), so it is a
  founder action: project `city-turfer-web`, root directory `apps/web`, framework Next.js.
  `apps/web/vercel.json` skips builds when nothing the web app depends on changed (`turbo-ignore`).
