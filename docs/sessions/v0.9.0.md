### `feat/record-map-brand` — dark app, Turf Map colours on Record (#111, open)

Founder requests: the Record map shows turf in the Turf Map's colours, and the app uses the
homepage's colours.

- **Record map:** always `MAP_STYLE_DARK`; turf drawn exactly as on the Turf Map. The lighter
  `overlay` look from #94 is gone (`TURF_LOOK` → one `TURF_STYLE`, `TurfLayers` lost `look`).
- **Whole app:** the website is dark only (`cssVariables('dark')`), so `app.json`
  `userInterfaceStyle` is `"dark"`: `usePalette()` returns `DARK` on every screen.
  - `expo-splash-screen` resets iOS `UIUserInterfaceStyle` to `Automatic` when its config has a
    `dark` block; the (identical) block is removed.
  - Android needs `expo-system-ui` for `userInterfaceStyle`; installed.
- Decision: `docs/engineering/architecture-decisions.md`, "The whole app is dark, like the website".
