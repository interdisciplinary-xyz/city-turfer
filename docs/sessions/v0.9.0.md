### `feat/record-map-brand` — dark app, Turf Map colours on Record (#111)

- **Record map:** always `MAP_STYLE_DARK`; turf drawn exactly as on the Turf Map (one `TURF_STYLE`).
- **Whole app:** `app.json` `userInterfaceStyle` is `"dark"`, so `usePalette()` returns `DARK`
  everywhere. The `expo-splash-screen` `dark` block is removed (it reset iOS to `Automatic`);
  Android got `expo-system-ui`.
- Decision: `docs/engineering/architecture-decisions.md`, "The whole app is dark, like the website".
