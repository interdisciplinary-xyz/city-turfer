# Session log — v0.2.0 (2026-10-16 → 2026-10-17)

v0.2.0 starts the features that come after the proof of concept: a **Me menu** (Profile, Account, Info) and **Achievements**. v0.1.0 was released on 2026-10-17 (#19, tag `v0.1.0`) and merged into this scope.

## Branches

```
feat/me-menu ─PR #15→ scope/v0.2.0 ─PR→ release/v0.2.0 ─PR→ main
feat/achievements ─PR #16 (stacked on #15)→ scope/v0.2.0
```

- `scope/v0.2.0` was cut from `scope/v0.1.0`; `release/v0.2.0` from `main`.
- 2026-10-17: `main` (v0.1.0 release + CHANGELOG) merged into `scope/v0.2.0`.
- Version pinned to `0.2.0` in `package.json`. `app.json` follows with the next native reinstall: its version is part of the runtime fingerprint, and changing it now would stop OTA updates to the installed build. It must be pinned before `release/v0.2.0 → main`.
- Rule from now on: feature branches → `scope/vX.Y.Z` → `release/vX.Y.Z` → `main`; stacked PRs carry `[n/N]` in the title.

## Built

| Area         | What                                                                                                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Me menu      | Tapping **Me** opens a menu above the tab bar: **Profile** (avatar, name, email, totals), **Account** (email, sign-in method, sign out), **Info** (app version, check for updates, data note, demo data). Menu items reachable by VoiceOver and Maestro.      |
| Achievements | New bounded context `achievements`: pure `evaluateAchievements` over activity and turf facts; 12 achievements (first steps, all-rounder, 5K, half marathon, half century, 100 km club, regular, early bird, night owl, neighbourhood, turf lord, stronghold). |
| Screens      | Achievements list with SF Symbol badges, progress bars, gold when unlocked; Profile shows the unlocked count.                                                                                                                                                 |
| Shared       | `weekStartOf` moved to the shared kernel (Stats and Achievements).                                                                                                                                                                                            |
