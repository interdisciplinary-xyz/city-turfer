# Android release (sideloaded APK)

Android users install CityTurfer from the website: a signed APK, no Play Store. iOS stays on
reinstalls from Xcode (free Apple ID) and OTA; see `docs/operations/ota-release.md`.

## One-time setup (founder)

1. **Vercel project** `city-turfer-web` (root directory `apps/web`, framework Next.js).
2. **Blob store** in that project (Storage → Create → Blob, public). Copy its
   `BLOB_READ_WRITE_TOKEN` into your shell or an untracked `.env` file, never into git.
3. After the first publish (below), set **`NEXT_PUBLIC_ANDROID_APK_URL`** on the Vercel project to
   the printed "Latest" URL. It never changes: every publish overwrites the same file.

## Build

```bash
pnpm -C apps/mobile run android:build      # EAS cloud build, profile android-apk
```

- Profile `android-apk` in `apps/mobile/eas.json`: APK, arm64-v8a only (about a third of the
  universal size), OTA channel `production`.
- **Version code** is managed by EAS (`appVersionSource: remote`, `autoIncrement`), so `app.json`
  stays untouched. The version name follows `app.json` `expo.version`.
- **Signing key**: generated by EAS on the first build and stored on Expo's servers (Project →
  Credentials). Every later APK must use the same key or phones refuse to update. Don't delete it;
  download a backup with `pnpm -C apps/mobile dlx eas-cli@latest credentials -p android`.
- Free tier builds queue; expect 10–40 minutes.

## Test before publishing

```bash
# Emulator (Android SDK in ~/Library/Android/sdk; AVD cityturfer-api35)
~/Library/Android/sdk/emulator/emulator -avd cityturfer-api35 &
adb install -r cityturfer.apk
adb shell pm grant com.turftrack.poc android.permission.ACCESS_FINE_LOCATION   # + COARSE, BACKGROUND, POST_NOTIFICATIONS
adb emu geo fix 21.0122 52.2497                                                # longitude latitude
cd apps/mobile && maestro --device emulator-5554 test e2e --config e2e/config.yaml -e DEV_URL=""
```

Check at least: launch, sign-in, a recording with the foreground-service notification, the Turf Map.
Background tracking still needs a real phone with the screen off.

## Publish

```bash
BLOB_READ_WRITE_TOKEN=… pnpm -C apps/mobile run android:publish   # newest finished android-apk build
BLOB_READ_WRITE_TOKEN=… pnpm -C apps/mobile run android:publish -- --build <eas-build-id>
```

It downloads the APK, prints its size and SHA-256, and uploads `android/cityturfer.apk` (the website
link, 60 s cache) plus `android/cityturfer-<version>-<versionCode>.apk` (history).

## Updates

- **JS-only changes**: publish an OTA (`docs/operations/ota-release.md`) with `--platform android`
  (or both). Installed APKs on the same runtime fingerprint pick it up on launch.
- **Native changes** (fingerprint moved, e.g. `app.json`, plugins, native dependencies): build and
  publish a new APK; people download it again and it installs over the old one (same signing key,
  higher version code).

## Known issues found

- 2026-10-18: crash on the first location update: `RECEIVE_BOOT_COMPLETED` was missing from the
  explicit permission list in `app.json` (expo-task-manager schedules a persisted job). Fixed.
