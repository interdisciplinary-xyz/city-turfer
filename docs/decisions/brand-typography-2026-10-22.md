# Brand typography: Street Plate (v0.10.0)

## Decision

The founder asked for a new font pairing; six were compared on the real copy (light site hero, the
dark app after a run, Polish lines), and **Street Plate** was chosen:

| Role       | Font                                  | Token                                    | Where                       |
| ---------- | ------------------------------------- | ---------------------------------------- | --------------------------- |
| Display    | Big Shoulders Display Black, capitals | `FONT_FAMILY.display`, `DISPLAY_CASE`    | app and web                 |
| Numbers    | Barlow Semi Condensed ExtraBold, tnum | `FONT_FAMILY.numeric`                    | app and web                 |
| Body (web) | Barlow 400 / 500 / 600 / 700          | `BODY_FONT_FAMILY`, `--font-family-body` | website, Swagger, Storybook |
| Body (app) | System font (SF Pro, Roboto)          | none                                     | app                         |

Display text is always uppercase (`DISPLAY_CASE`) with a little positive tracking
(`DISPLAY_TRACKING`, 0.4 pt); never negative tracking. The face is condensed, so headings are set
about a quarter larger than they were in Archivo Expanded.

**The wordmark follows (amended the same day).** At first it stayed outlined Archivo; the founder
then asked for the logo in the new face. It is now outlined Big Shoulders Display in capitals:
"CITY" Medium in night or blazing, "TURFER" Black in the Ramp, with the weight change doing what the
two capitals do in the written name (`packages/brand/svg/wordmark.svg` and
`packages/brand/svg/wordmark-light.svg`, generated by `packages/brand/scripts/outline-wordmark.py`).
In running text the name stays CityTurfer. Its proportions went from 5.7 : 1 to about 4.2 : 1, so
every fixed logo size was redone (site header and hero, /branding, Swagger, the app's sign-in
screen, the social image). The mark (hexagon), app icon and splash are unchanged; no Archivo is left
in the brand.

**Second amendment (same day):** the founder asked for a bold wordmark and a different face for the
tagline. The wordmark is now "CITY" and "TURFER" both in Black, told apart by colour (801 × 172,
about 4.7 : 1). The tagline "Surf your city. Own your streets." (website hero, /branding, social
image) is set in Barlow Semi Condensed Black Italic, sentence case (`TAGLINE_FONT_FAMILY`,
`--font-family-tagline`, web only): the slant reads as motion, and it no longer repeats the
wordmark's condensed capitals right below it. Other headings stay Big Shoulders Display.

This supersedes "Typography: Archivo" in `docs/decisions/brand-foundations-2026-10-20.md`.

## Why

- **The idea is streets.** Tall condensed capitals read like street-name plates and transit signs;
  "Own your streets" is literally what the type looks like.
- **Numbers fit.** Barlow Semi Condensed is narrow with tabular figures, so four stats sit across a
  phone with room to spare. Barlow was drawn from California road signs and plates, so body and
  numbers share the street-sign language.
- **Polish fits.** Archivo Expanded was so wide that long Polish headings wrapped early on 320 px
  phones; the condensed face holds "Zapisz się na listę oczekujących" in two lines.
- **Distinct.** Wide grotesques are common in sports-tech; condensed signage type is not.

Alternatives compared: Archivo (today), Overpass (road-sign, calmer), Unbounded + Manrope (the safe
evolution of the wide look), Anybody + IBM Plex (sporty italics, too close to performance tracking),
Bricolage Grotesque + DM Sans (quirky, likely to date).

## How

- `packages/brand/scripts/make-fonts.py` cuts static fonts from the Google Fonts sources (the
  variable Big Shoulders Display at weight 900, static Barlow files), subset to Latin + Latin
  Extended-A, PostScript name = file name. App fonts get `.ttf` + `.woff2`; the Barlow body weights
  are `.woff2` only.
- Licences: `packages/brand/fonts/OFL-BigShoulders.txt`, `OFL-Barlow.txt` (SIL OFL 1.1).
- Tokens in `packages/brand/src/tokens.ts`: `FONT_FAMILY`, `DISPLAY_CASE`, `DISPLAY_TRACKING`,
  `BODY_FONT_FAMILY`, and the `--font-family-*`, `--display-case`, `--display-tracking` CSS
  variables. `packages/brand/src/__tests__/tokens.test.ts` checks every font file exists.
- The rule stays: the weight is part of each font, so never combine a brand font with `fontWeight`
  (Android falls back to the system font); on the web use `font-weight: normal` and
  `font-synthesis: none` with the display and numeric faces.

## Consequences

- **Native change.** The app bundles the two new `.ttf` files through the `expo-font` plugin in
  `apps/mobile/app.json`, so the runtime fingerprint changes: a rebuild and reinstall is needed, and
  OTA updates for older builds would show the system font for headings and numbers.
- The social image (`apps/web/public/og-image.png`) is re-rendered with the new faces; the store
  screenshot template uses them too.
